# 🦁 Zoo online

Witamy w projekcie "Zoo online"! To niewielka aplikacja webowa stworzona do symulacji zarządzania wirtualnym ogrodem zoologicznym.

---

## 📖 O Projekcie

"Zoo online" to projekt hobbystyczny / edukacyjny, którego celem jest stworzenie prostego interfejsu do przeglądania i zarządzania kolekcją wirtualnych zwierząt.

### 🌟 Główne Funkcjonalności

* Przeglądanie listy wszystkich zwierząt w zoo.
* Dodawanie nowych zwierząt do kolekcji.
* Wyświetlanie szczegółowych informacji o każdym gatunku.
* (Opcjonalnie: Dodaj tu swoje inne funkcje, np. "Karmienie zwierząt" lub "Zarządzanie wybiegami").
